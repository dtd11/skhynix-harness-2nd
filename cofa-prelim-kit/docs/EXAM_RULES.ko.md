# 예선 규칙과 시간 계산

근거는 사용자가 제공한 `1_시험_필수확인사항_브리프.pdf`1쪽, `3_사전_체험_및_응시환경_상세_가이드.pdf`2~5쪽입니다. 이 문서는 핵심 조건을 요약한 것이며 최신 플랫폼/주최측 안내가 우선합니다. 원본PDF는 재배포하지 않습니다. 사용자는 본인이 만든 공개GitHub 저장소도 사용 가능하다고 주최측 확인 내용을 전달했습니다.

추가 확인: 사용자가 외부 자료는 **Git Clone으로 가져오는 것만 허용**된다고 전달했습니다. v1.1은 이 조건에 맞춰 추가 취득 경로를 Git Clone으로 한정하고 레지스트리 설치/URL 다운로드 기능을 제거했습니다. ZIP은 개인 PC에서 배포물을 준비하는 형식이며 시험 환경에 업로드하는 방식이 아닙니다.

## 공식 안내에서 확인한 조건

- 2026-10-31 10:00~14:00 KST 전체 운영. 과제 최대180분, 후속 서술형6문항×5분.
- `과제 시작`과 함께 녹화/작업 타이머가 시작됩니다. 서술형의 시작 버튼과 혼동하지 않습니다.
- 과제 제출 후 질문 생성 대기가 있습니다. 브리프는 약5분, 상세 가이드는 최대10분 안내와 재시도 가능성을 설명합니다. 대기는 답변 제한시간과 별개지만14:00 전체 종료에 포함됩니다.
- 제출 미리보기를 열어도 작업 시간은 계속 흐릅니다. 미리보기를 닫고 수정할 수 있으나 제출물 확정 후에는 파일을 수정할 수 없습니다.
- 작업 종료10분 전 제출을 시작하는 것을 권장합니다. 미리보기에서 숨김 폴더 등이 생략될 수 있으므로 미리보기 목록을 전체 제출 파일 목록으로 단정하지 않습니다.
- 서술형은 AI와 복사/붙여넣기를 사용할 수 없습니다. 이전 문항으로 돌아갈 수 없으며 다음 문항 시간은 직전 답안 제출 때부터 진행됩니다.
- 제공된 Codex 사용. 개인API키/개인유료구독/별도AI모델 연결, Astra, Claude Code 제한. Computer Use 자동 조작은 전 단계 금지.
- 공개Skill/MCP/Plugin/저장소 자료는 허용 범위에서 가져올 수 있습니다. 개인PC 파일 업로드, Git Push, 문제/파일/결과물의 외부 전송·공유, 감독/업로드 제한 우회는 금지됩니다.
- 외부 자료는 플랫폼 안의AI를 통해 활용하고 외부 브라우저에서 직접 접근하지 않습니다. 외부 결과물로 제출물을 통째로 대체하지 않습니다.
- Browser 미리보기는 실행 중인 앱 서버를0.0.0.0에 바인딩하고 실제 포트/경로를 입력합니다.3000은 예시입니다. 서버 터미널을 유지합니다.
- 과제에 요구된 문서와 파일명은 실제 문제를 따릅니다. 선택 이유·근거·검증·한계는 작업 중AI와 정리할 수 있습니다.
- 사용법/제출 절차는Cofa Helper, 업무 맥락은 제공된 실무자 에이전트, 반복 오류/연결 장애는문제 신고를 이용합니다. 신고로 타이머가 자동 정지·연장되지 않습니다. 본인 과다 프로세스 사용에 따른OOM은 구제 대상이 아닙니다.

## 키트가 추가한 권고

기본 `config/exam.json`의 질문 생성 여유10분은 키트의 보수적 추천값이며 공식 보장 시간이 아닙니다. 재시도에 더 오래 걸릴 수 있습니다.

```text
공식 작업 종료 추정 = min(실제 과제 시작 +180분, 전체 종료14:00)
권장 제출 확정 시각 = min(공식 작업 종료 추정, 전체 종료 -서술형30분 -질문 생성 여유10분)
권장 제출 시작 시각 = 권장 제출 확정 시각 -10분
```

10:00 시작: 작업 종료13:00, 권장 제출 시작12:50, 확정13:00.
12:50 시작: 작업 종료는14:00이지만, 서술형 여유를 고려한 권장 확정13:20/제출 시작13:10.
이미 권장 시각을 지났으면 여유가 부족하다고 표시합니다. 추가 시간을 만들거나 서술형 준비 지연을 해결했다고 주장하지 않습니다.

30분 남음: 선택 기능·대규모 리팩터링 중단을 권장합니다.10분 남음: 필수 파일·실행·저장·제출 흐름 우선. 이 단계 구분은 키트의 작업 전략입니다.
