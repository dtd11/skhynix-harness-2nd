# 검증 기록

검증일: 2026-10-30. 환경: Windows, Python 3.14.3, Node 24.16.0, Git 2.53.0. 실제 대회 과제나 응시 세션을 사용하지 않고 별도 임시 프로젝트와 자체 샘플로 확인했습니다.

## 하네스와 설치

`python -m unittest discover -s tests -v`의 38개 동작 검사를 수행했습니다. 설치 멱등성, 기존 AGENTS/패키지 선언 보존, 충돌 시 중단, 해시가 바뀐 스냅샷 거부, 목록에 없는 스킬 미활성화, 늦은 시작 시 시간 계산, 실패/시간 초과 기록, 코드 수정 후 증거 무효화, 제출 확정 이후 명령 거부를 포함합니다.

실행 중 검사에 마감/확정 상태를 반영하는지, 중단/예외 때 자식 프로세스를 종료하는지, 실제 종료코드 125를 검사 실패로 보존하는지, Windows 상대 실행 경로가 프로젝트 기준으로 해석되는지도 확인합니다. `.cofa`, `.venv-cofa`, 스킬 설치 경로가 외부 폴더로 연결된 경우에는 Windows junction으로 직접 검사했습니다.

8개 대회용 스킬은 skill-creator의 frontmatter 검증을 통과했습니다. Ruff 0.17.3으로 새 하네스·테스트·예제·매니페스트 스크립트의 기본 정적 오류를 검사했습니다. 제3자 원문을 일괄 포맷하거나 수정하지 않았습니다.

## 라이브러리 실행 기록과 v1.1 취득 조건

아래 라이브러리 실행 결과는 v1.0을 개인 PC에서 준비할 때 확인한 기록입니다. Git Clone만 허용된다는 추가 조건을 반영한 v1.1에서는 설치 기능을 제거했습니다. 이 기록은 시험 환경에서도 해당 도구를 받을 수 있거나 이미 제공된다는 근거가 아닙니다. v1.1의 `libraries`는 기존 환경을 조회만 하며, `--dry-run` 없이 실행해도 파일·패키지·가상환경을 만들지 않는 것을 검사합니다.

| 도구 | 실제 관찰 |
|---|---|
| DuckDB 2.0.0 | 자체 표의 합계 10 확인. 변경된 관계 객체 API를 반영해 `fetchall()` 사용 |
| NetworkX 3.7 | 가중 방향 그래프의 최단 경로 `a → b → c` 확인 |
| OR-Tools 9.15.6755 | 제약 `x >= 3`과 최소화 문제에서 실제 `OPTIMAL`, `x=3` 확인 |
| MarkItDown 0.1.9 | 로컬 CSV 및 자체 PDF/DOCX/XLSX/PPTX 샘플의 지정 텍스트 추출 확인 |
| React Flow 12.12.0 + Vitest 5.0.5 | 실제 노드 위치 변경/원본 보존과 중복 연결 방지 2개 검사 통과 |
| Ruff 0.17.3 | 새 Python 코드의 설정된 정적 검사 통과 |

원본 프로젝트가 주장하는 절약률·성능 향상을 이 키트에서 재현했다고 주장하지 않습니다.

## 행동 지침 검토

독립 검토자가 늦은 시작, 마감 8분 전 오류, 확인하지 않은 UI, 서술형 전환, 제공 모델 장애의 5개 가상 상황을 검토했습니다. 기본 판단도 이 상황들을 올바르게 처리했으므로 행동 개선율을 측정한 실험은 아닙니다. 키트는 시간/단계/검증 기록을 재현 가능하게 만드는 보조 기능을 추가합니다.

별도 코드 검토에서 발견한 소스 지문 누락, 실행 중 단계 전환, 미등록 스킬 설치, 경로 이탈, 자식 프로세스 정리, 종료코드 구분, Windows 상대 경로 문제를 수정하고 회귀 검사에 넣었습니다.

## 미확인 범위

- 시험장 Linux, 네트워크, 제공된 Codex의 스킬 발견/권한은 직접 확인하지 않았습니다. 사전 체험에서 설치·짧은 요청·필요한 패키지를 확인해야 합니다.
- 기본 하네스는 제공된 Python 표준 라이브러리만 사용합니다. 참고 라이브러리의 실행 조건은 버전에 따라 다릅니다. 패키지가 제공되지 않아도 기본 하네스는 사용할 수 있습니다. 별도 설치 명령은 만들거나 실행하지 않습니다.
- 라이브러리 검사는 작은 실제 연산/변환입니다. 복잡한 문서, 모든 그래프/최적화 문제, 앱 UI 전체를 검증한 결과는 아닙니다. 브라우저 자동화는 실행하지 않았습니다.
- 남은 시간과 준비 여유는 로컬 추정입니다. 공식 타이머·제출·확정은 플랫폼이 관리합니다. 보조 도구가 단계나 규칙을 OS 수준으로 강제하는 것은 아닙니다.
- 소스 지문은 알려진 루트 출력/의존성 폴더를 제외합니다. 외부 심볼릭 링크 대상 내용까지 신선함을 보장하지 않습니다. 검사와 요구사항의 대응은 구현자가 확인해야 합니다.
- 스킬 원본은 커밋을 고정해 선택 경로만 보관했습니다. 7개 라이브러리의 전체 실행 코드·의존성·바이너리를 모두 포함한 배포물은 아닙니다. 제공 환경을 사용하고, 필요한 소스의 취득은 Git Clone만 허용하는 구성입니다.

## Git 전송 확인

`.gitattributes`로 파일 바이트를 보존하고, 자체 임시 Git 저장소를 만든 뒤 core.autocrlf=true로 등록하고 false로 Clone한 결과의 전체 무결성을 검사합니다. 이는 로컬 Git 전송 검사입니다. 게시된 공개 저장소의 Clone 확인은 배포 확인 기록에서 별도로 다루며, 실제 시험 환경의 Clone/권한은 사전 체험에서 확인해야 합니다. 레지스트리/URL 다운로드 명령 거부와 라이브러리 조회의 무변경 동작도 v1.1 검사에 포함합니다.
